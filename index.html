03 / PRODUCTION CASE STUDY

Golden Circle: Derby reservations in Discord

Golden Circle · Community project in production
  • Python
  • Discord.py
  • Supabase
  • PostgreSQL

I built a Discord bot that helps Golden Circle’s Hay Day neighborhoods coordinate derby task reservations without leaving Discord. Members reserve tasks with message reactions, and staff can view and manage reservations in one place.

Members can step away without losing track of their picks. The bot saves their selections when they opt out and restores the ones that are still available when they return.

Supabase stores reservations and configuration across neighborhoods. The source code remains private.
